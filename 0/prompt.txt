## Hide planning without deleting it

- `docs/plan/`, `TODO.md`, `ROADMAP.md` → gitignore the scratch ones, or keep them but **do not** mention them in README
- GitHub: Settings → General → uncheck “Releases / Packages / Deployments” you don’t use so the right rail isn’t noise
- Pin nothing that says “planning”
- `CONTRIBUTING.md` can exist; README gets one word: `Contributing` as a link, no preview of the process
