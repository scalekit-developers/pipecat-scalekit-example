# Developers bring their own Google OAuth app

This sample is for other developers. Google Calendar has no Scalekit-managed OAuth app today. We document dashboard setup: create a Google Cloud OAuth client, paste it into the Scalekit connection, connect their Google account, put their identifier in `.env`.

We do not wait for future Scalekit-managed credentials. When that ships, README can add a shorter path. The `.env` contract stays the same.
