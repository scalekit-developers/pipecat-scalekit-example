# Scalekit is AgentKit only. The LLM is OpenAI.

This sample teaches AgentKit: connection, connected account, `execute_tool`.

`llm.scalekit.cloud` is an internal proxy for Scalekit team members. It is not a product. Do not put it in the README.

External developers use a real OpenAI key, like the Pipecat quickstart.

Scalekit team members may use a real OpenAI key or the internal proxy for their own run. AgentKit is required either way.
