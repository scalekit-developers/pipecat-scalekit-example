You speak. Pipecat Cloud talks. Scalekit reads Calendar.

The model never sees a Google token. The browser never sees a Scalekit secret.

You Pipecat Cloud Scalekit Google Calendar
1
You → Pipecat Cloud
Open the Cloud client. Click Connect. Say “What’s on my calendar today?”
Audio goes to Daily WebRTC inside Pipecat Cloud. Not localhost.
2
Pipecat Cloud
Speech-to-text turns your voice into text.
Deepgram (or another cloud STT). Local Whisper is gone.
3
Pipecat Cloud → LLM
The language model sees the text and the tool name only.
It may call googlecalendar_list_events. It does not receive a token.
4
Pipecat Cloud → Scalekit
Our bot calls execute_tool as TEST_IDENTIFIER.
Same contract as Vapi and LiveKit. Secrets stay in the Cloud secret set.
5
Scalekit → Google
Scalekit uses the stored Google connection. Google returns events.
OAuth lives in Scalekit. Not in Pipecat. Not in the LLM.
6
Pipecat Cloud → You
The model writes a short spoken answer. Text-to-speech plays it.
You hear the meetings. End of turn.
Never on this path: Google password, OAuth token, Scalekit client secret in the browser, Pipecat OSS localhost:7860.
